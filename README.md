# Smart-Campus-Intelligence

Smart Campus Intelligence is an AI-powered campus management platform designed to enhance the student experience and simplify college administration through intelligent digital solutions.

The platform brings together multiple campus services in one place, including an AI Campus Assistant that provides information about college facilities, departments, events and procedures; Smart Event Management for event discovery and student registrations; and an AI-powered Student Feedback & Helpdesk system that analyses feedback, classifies complaints and identifies sentiment trends.

It also features an Admin Dashboard that provides insights into student feedback, complaint patterns and event participation, helping administrators make more informed, data-driven decisions.

Key Modules:

AI Campus Assistant using Retrieval-Augmented Generation (RAG)

Smart Event Management and Registration

AI-Powered Student Feedback and Complaint Classification

Admin Dashboard and Campus Insights

Proposed Technology Stack: Python, Streamlit, SQLite, Pandas, Scikit-learn, and Generative AI / LLM APIs.

The project aims to create a more connected, responsive and intelligent campus ecosystem by bringing essential student services and administrative insights together on a single platform.
