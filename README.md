# Smart Campus Intelligence 🎓
### An AI-Powered Campus Management Platform

Smart Campus Intelligence is an AI-powered campus management platform designed to make college operations more organised, accessible and data-driven. It integrates student assistance, event management, intelligent feedback analysis and administrative insights into a unified application.

The platform aims to improve the campus experience for students while helping administrators make informed decisions through data analytics and AI-driven insights.

## 🎯 Project Objectives
- Provide students with easy access to campus-related information through an AI-powered assistant.
- Simplify college event discovery and student registration.
- Automate the categorisation and sentiment analysis of student feedback.
- Help administrators identify recurring issues and understand student experiences.
- Enable data-driven decision-making through an interactive administrative dashboard.

## 🚀 Key Features
### 1. AI Campus Assistant
- Provides answers to campus-related queries.
- Retrieves information from college-provided documents.
- Uses Retrieval-Augmented Generation (RAG) to provide context-aware responses.
- Helps students access information about departments, facilities, events and college procedures.

### 2. Smart Event Management
- Displays upcoming college events.
- Enables students to register for events.
- Allows administrators to manage event information.
- Maintains event registration records.

### 3. Student Feedback & Smart Helpdesk Intelligence
- Collects student feedback and complaints.
- Automatically classifies feedback into relevant categories.
- Performs sentiment analysis to identify positive, negative and neutral feedback.
- Assigns basic priority levels to help identify issues requiring attention.
- Generates structured feedback insights for administrators.

### 4. Admin Dashboard & Campus Insights
- Provides an overview of campus activities.
- Visualises feedback and complaint trends.
- Displays sentiment and category distributions.
- Presents event registration analytics.
- Supports data-driven administrative decisions.

## 🧠 AI & Machine Learning Approach
The platform incorporates AI and machine learning to make campus operations more intelligent.

The feedback intelligence module will explore:
- Text preprocessing and cleaning.
- Feature extraction using techniques such as TF-IDF.
- Feedback classification using machine learning algorithms.
- Sentiment analysis.
- Model evaluation using accuracy, precision, recall and F1-score.

The AI Campus Assistant will explore document-based information retrieval using embeddings, vector search and Large Language Models.

## 🏗️ Proposed System Architecture
The application is organised into four interconnected modules:

1. AI Campus Assistant
2. Smart Event Management
3. Student Feedback Intelligence
4. Admin Dashboard & Campus Insights

These modules will interact with the application's data layer to provide a unified campus management experience.
